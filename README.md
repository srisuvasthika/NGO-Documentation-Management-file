# 🌱 NGO Documentation Management System

## 📌 About the Project

The *NGO Documentation Management System* is a documentation repository developed for *HopeBridge Foundation*.

The purpose of this project is to organize and manage important NGO documents such as the NGO profile, event reports, volunteer guidelines, awareness materials, photographs, and meeting minutes in one centralized location.

## 🎯 Objectives

- Organize NGO documents in a structured manner.
- Maintain records of NGO events and activities.
- Provide guidelines for volunteers.
- Share awareness materials with the community.
- Maintain a photo gallery of NGO activities.
- Record meeting discussions and decisions.
- Improve teamwork and collaboration using GitHub.

## 📂 Repository Contents

| Folder | Description |
|---|---|
| NGO-Profile | Information about the NGO |
| Event-Reports | Reports of NGO events and activities |
| Volunteer-Handbook | Volunteer responsibilities and guidelines |
| Awareness-Materials | Health, education, and environmental awareness materials |
| Photo-Gallery | Photographs from NGO activities |
| Meeting-Minutes | Records of meetings, decisions, and action items |

## 📖 Documentation

### 🏢 NGO Profile

Contains the NGO's vision, mission, objectives, areas of work, and target beneficiaries.

### 🎉 Event Reports

Contains detailed reports of NGO activities and community events.

### 👥 Volunteer Handbook

Provides information about volunteer responsibilities, code of conduct, communication, safety, and event participation.

### 📢 Awareness Materials

Contains awareness information related to:

- Health
- Education
- Environment

### 📸 Photo Gallery

Contains photographs documenting NGO events and activities.

### 📝 Meeting Minutes

Contains records of meetings, discussions, decisions, and assigned tasks.
